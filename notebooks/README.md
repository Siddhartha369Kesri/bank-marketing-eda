Jupyter Notebooks – Bank Marketing EDA

This folder contains the Jupyter Notebook used to perform Exploratory Data Analysis (EDA) on the Bank Marketing Dataset.

File Name: "bank_marketing_eda.ipynb"

Tools and Libraries:
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Analysis Performed:
1. Data loading and inspection
2. Dataset structure and information
3. Data cleaning and preprocessing
4. Target variable analysis ("y")
5. Customer age group analysis
6. Job, education and marital status analysis
7. Account balance analysis
8. Housing and personal loan analysis
9. Campaign contact frequency analysis
10. Previous campaign outcome analysis
11. Call duration analysis
12. Correlation analysis using a heatmap



To explore customer characteristics, understand campaign performance and identify patterns associated with term deposit subscriptions.
