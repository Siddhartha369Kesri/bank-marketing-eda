Project Reports – Bank Marketing EDA

This folder contains the reports generated from the Exploratory Data Analysis of the Bank Marketing Dataset.

The reports present important observations, visualizations and insights obtained during the analysis.

Reports Included
1. HTML Report
File Name: "bank_marketing_eda.html"

An interactive browser-readable version of the Jupyter Notebook analysis.

2. PDF Report
File Name: "Bank_Marketing_eda_report.pdf"

A document containing the project's analysis, visualizations, key findings and conclusion.

Key Analysis Areas:
- Customer subscription behaviour
- Customer demographics
- Loan-related analysis
- Campaign contact frequency
- Previous campaign performance
- Call duration and subscription
- Correlation between numerical variables


Purpose:
To present the EDA results in an organized and understandable format for project review and future reference.

Note: The HTML and PDF report files will be added to this folder later.
